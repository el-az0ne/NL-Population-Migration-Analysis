# Population and Migration Analysis in Newfoundland and Labrador (2000–2025)

## Project Overview

This project explores population trends and migration patterns in Newfoundland and Labrador, Canada, from 2000 to 2025.

The goal is to understand how natural population change and migration have influenced the province's demographic development.

## Research Questions

- How has the population changed over the past 25 years?
- What are the trends in births, deaths, and natural population change?
- How have international and interprovincial migration affected population growth?
- What role have temporary residents played in recent demographic changes?

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings

- Newfoundland and Labrador experienced a prolonged period of population decline, followed by renewed growth.
- Natural population change has remained negative since 2011/2012.
- Migration has become an important contributor to population growth.
- Recent population growth has occurred despite deaths exceeding births.
